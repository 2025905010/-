# Fútbol Desk — 라리가 한국어 정보 대시보드

기존 스포츠 대시보드의 기본 형식을 유지하고, 내용과 데이터 모델을 스페인 프로축구 1부 리그 **라리가(LaLiga)** 중심으로 바꾼 교육용 프로젝트입니다.

## 주요 기능

| 메뉴 | 설명 |
|---|---|
| 홈 | 라리가 소개, 오늘의 경기, 다가오는 경기, 관심 구단 |
| 경기 | 한국시간 날짜별 일정과 점수 |
| 선수 | 구단별 선수 명단(공개 API가 제공하는 범위) |
| 순위 | 현재 순위표와 승점 그래프 |
| 구단 | 참가 구단 목록과 기본 정보 |
| 구장 | 구단별 홈구장 정보(제공되는 경우) |
| 뉴스 | 축구 뉴스 기사 링크(공개 API 제공 범위) |
| 텔레그램 봇 | 오늘 경기, 순위, 구단 목록, 관심 구단 경기 |

## 실행 방법 (Windows 10/11)

1. ZIP 파일의 압축을 풉니다.
2. `setup.bat`을 실행합니다. 처음 한 번만 실행하면 됩니다.
3. `run_web.bat`을 실행합니다.
4. 브라우저에서 Streamlit이 표시하는 주소(보통 `http://localhost:8501`)를 엽니다.

Python 3.11 이상과 인터넷 연결이 필요합니다.

## 텔레그램 봇 (선택 사항)

1. Telegram의 `@BotFather`에서 봇 토큰을 발급받습니다.
2. 명령 프롬프트에서 아래처럼 토큰을 설정합니다.
   ```bat
   set TELEGRAM_BOT_TOKEN=발급받은_토큰
   run_bot.bat
   ```
3. 봇에서 `/start`를 입력합니다.

지원 명령어:
- `/score` 오늘의 경기
- `/ranking` 현재 순위
- `/teams` 구단 목록
- `/fav Real Madrid` 관심 구단 설정
- `/myteam` 관심 구단의 최근/예정 경기

## 데이터 및 주의사항

- 경기, 구단, 순위, 뉴스는 ESPN 공개 축구 API 엔드포인트를 이용합니다.
- 이 엔드포인트는 공식 LaLiga API가 아니며, 구조와 접근 가능 여부가 예고 없이 바뀔 수 있습니다.
- API에서 제공하지 않는 선수 기록이나 구장 세부 정보는 임의로 만들어 넣지 않고, 이용 불가 안내를 표시합니다.
- 캐시는 `data/cache/`에 저장됩니다. 네트워크 요청이 실패하면 마지막 정상 응답을 사용할 수 있습니다.
- 현재 환경에서는 실제 외부 API, 브라우저 UI, 텔레그램 실전 발송까지 통합 검증할 수 없으므로 최초 실행 후 데이터를 확인해야 합니다.
- 실제 경기 일정/결과와 뉴스의 저작권 및 이용 조건을 준수하세요.

## 데이터 표시 오류 수정판
- 라리가 순위는 ESPN의 `/apis/v2/` standings 경로로 요청하도록 수정했습니다.
- 순위 응답의 중첩된 그룹 구조를 처리합니다.
- 구단 목록과 선수 명단 응답을 보다 유연하게 처리합니다.
- ESPN 공개 API는 비공식이며 외부 서버나 네트워크에 따라 일시적으로 실패할 수 있습니다.
